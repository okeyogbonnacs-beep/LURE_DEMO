BUTTONS_READ_ME.txt

Some button files may contain names ending with:

_ani

Example:

- play_button_ani
- settings_button_ani

The "_ani" label means the button contains animation frames or animated button visuals.

These files are intended for:

- hover animations
- menu transitions
- interactive UI effects
- animated interface presentation
